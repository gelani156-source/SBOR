# СБОР — этап 1: рабочий прототип интерфейса

Основа React 19 + TypeScript + Vite, настроенная для GitHub Pages.

**Сборка локально ещё не подтверждена из-за недоступности npm-зависимостей в среде подготовки. Результат проверяем в GitHub Actions.**

**Важно:** на этапе 1 нет Supabase, регистрации, внешних карт, уведомлений и сетевой синхронизации. Данные демонстрации сохраняются только в локальном хранилище браузера данного устройства и не являются общими. Финансовые данные пока тестовые.

## Как установить через GitHub на iPhone
1. Создайте новый репозиторий `SBOR` без README и других автоматически создаваемых файлов.
2. Распакуйте архив в «Файлах» и загрузите содержимое папки SBOR_STAGE1 **в корень репозитория**, сохраняя вложенность `src/`, `public/`, `.github/workflows/`.
3. В репозитории откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Проверьте **Actions → Publish SBOR preview** (зелёная галочка).
5. Ссылка обычно вида `https://<пользователь>.github.io/SBOR/` — реальную ссылку смотрите в Pages/Actions.

Если Safari на iPhone скрывает файлы с точкой (`.github`, `.gitignore`) при загрузке, создайте их редактором GitHub; можно загрузить проект с компьютера или через Codespaces.
